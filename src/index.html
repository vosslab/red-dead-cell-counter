Object measurements

Connected threshold objects, not cell boundaries.

Measurements of single-center objects away from image edges; SD is population standard deviation, n is the number of finite measurements.
Measure Mean Median SD n

What these measurements mean
Area
Pixels in one 8-connected object in the final DoG threshold mask.
Equivalent diameter
Diameter of a circle with the same area: √(4 × area / π).
Roundness
4π × area / perimeter². A circle is near 1; raster perimeter approximation can give values above 1.
Inertia ratio
Major / minor eigenvalue of the binary object covariance. Near 1 means similar spread; larger values mean more elongated.
Mean squared radius
Mean squared pixel distance from the object's centroid, in px² (covariance trace). This binary area moment is not an intensity-weighted moment.

Means, medians and population SD use only single-center objects away from image edges. Each n counts finite values. Multiple-center objects have one shared area, not an area per cell. Edge counts overlap the center groups.
